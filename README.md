# University Admission Management System

A C++ console-based University Admission Management System developed using Object-Oriented Programming (OOP) concepts and CSV file handling.

## Features
- Student Registration & Login
- Teacher Registration & Login
- Admin Dashboard
- Student Approval/Rejection
- Teacher Approval/Rejection
- Teacher Assignment to Students
- Assignment Management
- Student & Teacher Profile Management
- Report Creation and Viewing
- CSV Database Storage

## Technologies
- C++
- Object-Oriented Programming (OOP)
- File Handling (CSV)
